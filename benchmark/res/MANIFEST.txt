----------------------------------------------------------------
METHODOLOGY
----------------------------------------------------------------
- Each benchmark data point runs in a forked child (bench_fork) so the
  glibc heap is fresh per run; RSS sampled from /proc/self/status (VmRSS).
- Timing: clock_gettime(CLOCK_MONOTONIC).
- n = 3 trials for cpu/io/scaling/queue/heterogeneous; aging n = 5;
  stability = 50 sustained iterations (single long-lived pool).
- Comparative tables: mean +/- sample stddev (n-1) and CV%, via
  parse_to_latex.py. It now auto-generates ALL benchmark tables into
  tables.tex: cpu/io/scaling/queue, heterogeneous, stability, and the
  tail-latency tables (read from demo/bench_results/latency_summary_*.csv).
- A/B run benchmark_heterogeneous — branches A/B (mine/base), n = 10

----------------------------------------------------------------
